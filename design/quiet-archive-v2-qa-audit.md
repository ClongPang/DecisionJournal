# Quiet Archive 2.0 · 页面验收清单

本清单记录四角色评审后的实现与设备验收范围。首席开发负责实现和测试；产品经理关注任务闭环与可找回性；UI 设计师关注信息层级、留白、触控和缩放；资深用户关注历史、异常说明与中断恢复。

## 页面与状态

| 页面／模块 | 已验收的关键元素与状态 |
| --- | --- |
| 今日 | 空态、预热待回看封面、待回看集合入口、主创建操作、读屏详情入口 |
| 全部决定 | 状态矩阵、时间范围、关键词搜索、搜索空态、搜索与筛选叠加、时间线读屏入口 |
| 我的档案 | 统计、可追溯洞察、洞察到关键词搜索的下钻、色彩层级 |
| 新的决定 | 三步进度、候选项、最终选择、信心、日期、通知说明、未保存离开确认、Activity 重建恢复 |
| 决定详情 | 候选项与上下文、预期对照、状态化回看操作、回看历史、删除影响说明、缺失记录恢复页 |
| 回看 | 原始决定上下文、已有历史提示、预期矩阵、满意度、下一次回看、未保存离开确认、Activity 重建恢复 |
| 提醒 | 无效提醒深链恢复页；提醒安排失败时提供重试与系统通知设置入口 |

## 数据与设备证据

- Debug 预热入口通过 `extra_debug_warmup_data` 建立待回看、等待中、已回看、未设日期及多次回看的样本。
- 已连接的 `Pixel_10a (AVD)` 模拟器检查了首页预热态、无数据首页、无数据列表、无数据档案、列表状态筛选、档案概览与洞察、创建首步、详情、回看及无效提醒深链恢复。首页、列表、详情和档案截图中未发现内部“预热”标记；无数据页面均有明确说明与“记录一个决定”入口；页签切换后档案页从顶部完整显示；创建、详情和回看中的标题换行、卡片边界、结果选择与底部安全区可完整显示。
- 实体机复核仍待进行：系统通知总开关／频道关闭、权限拒绝后的设置跳转及 1.3× 字体缩放。模拟器结果不替代这些系统级场景。
- 在 `Pixel_10a (AVD)` 模拟器的 1.3× 字体比例下，首页叙事卡、列表状态矩阵、筛选器、日期范围与列表标题完整显示，无裁切或触控重叠；检查后已恢复为 1.0×。档案洞察下钻与带参搜索仍待实体机复核。
- 已连接设备的 `DecisionDaoTest` 曾执行 9 项断言，结果为 `failures=0, errors=0`，覆盖决定、候选项、回看历史、日期重排和删除级联。

## 自动化门禁

- `assembleDebug`、`testDebugUnitTest`、`lintDebug` 均通过。
- `git diff --check` 通过。
- 表单恢复采用 Android 保存实例状态：系统重建 Activity（例如旋转）可恢复当前输入；用户主动放弃或强制停止应用不会把未保存内容写入决定库。
