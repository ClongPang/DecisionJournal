## 五、本期修改范围（交给开发师，共 19 项）

### A. 数据正确性（P0）
- **A1** 更正复盘时，下一次回看日期 / 不再提醒的改动生效：`DecisionRepository.review()` 编辑分支也按 `input.nextReviewDate` 更新决定调度、状态与提醒，与新增分支对齐；补单元测试。

### B. 文案与术语（暴露文本核查）
- **B1** 统一状态术语：待回看 / 等待回看 / 已回看 / 未设日期 / 已有复盘；抽一个共享状态标签函数供首页/决定/详情复用（含首页"此刻的判断"统一）。
- **B2** 创建第三步：`reviewDate == null` 时文案改为"不设置回看日期也可以保存，之后仍可随时补充"，只有选了日期才显示提醒说明。
- **B3** 通知正文带决策问题：「{question}」到了复盘时间（超长截断），Worker 已有 decision。
- **B4** 文案小修：删除确认按数量分支（无复盘时不显示"0 条回看"）；我的概览卡"10 段记录"语病；空态"写下/留下"统一；命中来源补"预期"（→"背景、预期或写给未来"）。

### C. 交互与可发现性（P1）
- **C1** 搜索框加尾部"清除"（X）按钮（带 contentDescription）；无结果空态加 `imePadding` 并在键盘收起后位于首屏。
- **C2** 候选卡整行可点选为最终选择（行级 toggleable，动作按钮行保持独立）。
- **C3** 保存失败错误提示固定在底部操作栏上方，避免被折叠区遮挡。

### D. 无障碍（P1）
- **D1** 复盘预期/满意度 chip、创建信心选择器补 checked 语义（toggleable / semantics checked）。
- **D2** 底部导航三项显式语义标签 + selected 状态（注明需 TalkBack 实测复核）。
- **D3** 搜索命中来源并入 TimelineItem 的 accessibilityLabel。

### E. 视觉与尺寸一致性（P2，本次重点）
- **E1** 卡片内边距 token 收敛为两档：常规 16dp / hero·叙事 20dp；消灭 14/15/18/24 散点与"我的"页 108/120 左缘漂移。
- **E2** 小操作按钮统一 48dp：上移/下移/编辑/删除、添加这个选项、更正/删除、重新安排提醒；详情"编辑/现在回看"行 48dp。
- **E3** 筛选 chip 补 `overflow = TextOverflow.Ellipsis`，1.3x 大字体不裁切。
- **E4** 时间线/详情日期：非当年补年份（如"2025年8月3日"），当年保持"8月3日"。
- **E5** 复盘间隔改日历天差（`ChronoUnit.DAYS.between`），跨午夜即算 1 天；补单元测试。

### F. 演示数据（P2）
- **F1** `DemoDataSeeder`：担忧词库增加多样性（降低"执行成本"占比）、满意度分布更自然（"符合预期"样本满意度≥3）、近期创建记录分散到不同周/月。

### 延后（明确记录，不在本期）
