# 回看 MVP 验收清单

执行方式：使用 `ANDROID_USER_HOME="$PWD/.android-user-home" ./build-debug.sh` 构建 Debug APK 后，在 Android 模拟器或 Android 手机上逐项验证。

| 编号 | 验收场景 | 验证结果 |
|---|---|---|
| AC-001 | 空数据进入首页，显示空状态和“记录一个决定”入口 | 手工验证 |
| AC-002 | 问题为空时保存按钮不可用 | 手工验证 |
| AC-003 | 没有候选选项时阻止保存 | 自动化 + 手工验证 |
| AC-004 | 有效问题和选项保存后出现在列表 | 手工验证 |
| AC-005 | 多个选项只能显示一个最终选择 | 手工验证 |
| AC-006 | 设置未来日期后创建唯一 WorkManager 提醒 | 手工验证 |
| AC-007 | 日期到达后首页显示待复盘决策 | 手工验证 |
| AC-008 | 保存复盘后详情保留原始决策并显示复盘 | 手工验证 |
| AC-009 | 多条复盘按时间倒序显示 | 手工验证 |
| AC-010 | 取消删除确认时数据保留，确认后级联删除 | 手工验证 |
| AC-011 | 飞行模式下完成创建、编辑、查看和复盘 | 手工验证 |
| AC-012 | 重启应用后数据仍存在 | 手工验证 |
| AC-013 | 满意度超出 1～5 时拒绝提交 | 自动化 + 手工验证 |
| AC-014 | 保存复盘时设置下一次日期，决策保留为可待复盘状态并重新安排提醒 | 自动化 + 手工验证 |
| AC-015 | 保存复盘时不设置下一次日期，取消后续提醒但保留复盘历史 | 自动化 + 手工验证 |
| AC-016 | 已结束提醒的决策仍可从详情页再次发起复盘 | 手工验证 |

补充边界检查：空格输入、删除唯一选项、删除已选选项、清除复盘日期、重复点击保存、删除决策后返回列表。
